    Why this dashboard is intentionally boring

    The Sustainable Software Engineering playbook (HPI / AWS Sustainability Pillar / Green Software Foundation) treats carbon as a first-class non-functional requirement: ship the least software that solves the problem. Every technique below is measurable — the audit on the right is the receipt.

    • ✓Static HTML + hand-rolled JS (no SPA framework, no bundler, no polyfills) — the Angular/Next.js bundle for this feature set would start at ~200 KB gzipped.
    • ✓~3 KB custom canvas chart module instead of a full charting library (often 100 KB+).
    • ✓Douglas-Peucker simplified GeoJSON, ≤ 3-decimal coordinates (~100 m precision at this zoom) and rounded attributes — layers re-exported under a strict byte budget.
    • ✓System font stack — zero webfont requests, zero font reflow.
    • ✓Dark theme (fewer lit pixels on OLED) and prefers-reduced-motion respected.
    • ✓No client polling loops; every widget renders on demand — compute happens once per interaction, not per heartbeat.
